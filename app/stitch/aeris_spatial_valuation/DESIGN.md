## Brand & Style

The design system establishes a high-precision, institutional-grade analytical environment for automated property valuations and spatial geospatial intelligence. It translates complex machine learning regressors (XGBoost, LightGBM, SHAP feature attribution) into clear, trust-inspiring decision tools for property analysts, institutional investors, and urban planners.

The visual direction merges **Clean Glassmorphism** with **Technical Precision Spatial Design**:
- **Atmospheric Transparency**: Interfaces float across spatial map layers using frosted backdrop surfaces, subtle multi-layered inner borders, and light-refracting edge highlights.
- **Cognitive Clarity**: Data density is managed through crisp typographic scale, high-legibility tabular figures, and balanced neutral canvases that keep cartographic and econometric charts readable.
- **Empirical Trust**: Every prediction is paired with explicit confidence bounds and explainability drivers, using an intentional palette of growth-oriented emeralds, analytical ceruleans, and calibrated alert states.

## Colors

The palette is engineered for high data-density spatial dashboards, anchoring valuation intelligence around deep emerald greens and oceanic ceruleans:

- **Primary (`#059669`)**: Drives positive financial valuation gains, high-confidence metrics, affirmative action buttons, and upward SHAP attributions.
- **Secondary (`#0284C7`)**: Anchors geospatial coordinates, active map boundary highlights, polygon filters, and active tab states.
- **Tertiary (`#6366F1`)**: Reserved for predictive simulation scenarios, ROI modeling parameters, and machine learning diagnostic indicators.
- **Neutral (`#64748B`)**: Scales interface contrast from dark slate headers (`#0F172A`) down through soft borders and muted metadata (`#94A3B8`).

### Market Tier Palette
- **Entry-Level**: Emerald Teal (`#0D9488`) for accessible starter homes and median King County cohorts.
- **Mid-Market**: Deep Cerulean (`#0284C7`) for balanced suburban inventory.
- **Luxury Tier**: Royal Amethyst (`#7C3AED`) representing top-percentile and waterfront estates.

### Spatial & Glass Surfaces
Translucent backgrounds utilize high-alpha white mixes (`rgba(255, 255, 255, 0.78)`) backed by pure-light canvas backings (`rgba(248, 250, 252, 0.72)`) to allow underlying satellite imagery or GIS vector base-maps to softly register without degrading chart or label contrast.

## Typography

Typography pairs **Plus Jakarta Sans** for structural layout and narrative reading with **JetBrains Mono** for machine-learning feature keys, spatial coordinates (lat/long), confidence bands, and currency data.

### Typographic Hierarchy Rules
- **Numerical Primacy**: All financial valuation numbers (`$845,200`), model scores ($R^2$, MAPE), and square footage metrics use tabular figures (`font-variant-numeric: tabular-nums`) to ensure strict columnar vertical alignment.
- **Technical Footnotes & Code**: Feature tokens (`SqFtTotLiving`, `grade_num`, `zipcode_98004`) and raw statistical bounds are strictly set in `label-mono`.
- **Headers**: Display sizes use tight negative tracking (`-0.025em`) to retain a sharp, executive product feel.

## Layout & Spacing

The dashboard employs an adaptive 12-column analytical grid with asymmetric pane zoning:

- **Sidebar Controller (Cols 1–3)**: Fixed 320px–360px on desktop or 3-column span; houses property attributes, King County ZipCode selectors, and interactive sliders (Grade 1–13, Bathrooms, SqFt).
- **Core Intelligence Canvas (Cols 4–8)**: Dynamic fluid viewport accommodating the interactive Leaflet/Mapbox GIS container, valuation prediction badge overlay, and confidence interval brackets.
- **Diagnostics & ROI Simulator (Cols 9–12)**: Vertical stacked glass stack presenting SHAP waterfall attribution, value-add renovation scenarios, and neighborhood comp tables.

### Responsive Breakpoints
- **Desktop (>= 1280px)**: 12-column persistent tripartite arrangement; map and sidebars simultaneously visible with 24px gutters.
- **Tablet (768px – 1279px)**: Split-screen tabbed interface with collapsible bottom drawer for SHAP analytics.
- **Mobile (< 768px)**: Single-column stack; map docks to top 300px viewport, controllers convert to modal sheet triggers, and valuation cards occupy full width.

## Elevation & Depth

Visual hierarchy uses frosted optical glass layers combined with ambient low-opacity shadow diffusion:

### Glassmorphism Specification
- **Base Canvas Layer (L0)**: Continuous interactive map canvas or background GIS terrain view.
- **Translucent Deck (L1)**: Large application containers use `backdrop-filter: blur(20px) saturate(180%)`, surface fill `rgba(255, 255, 255, 0.78)`, border `1px solid rgba(255, 255, 255, 0.65)`, and a drop shadow of `0 12px 32px -4px rgba(15, 23, 42, 0.08)`.
- **Card Tier (L2 - KPI & Filter Tiles)**: Floating micro-cards with `backdrop-filter: blur(12px)`, background `rgba(255, 255, 255, 0.88)`, border `1px solid rgba(255, 255, 255, 0.9)`, and an inset specular rim highlight: `box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.9), 0 4px 16px -2px rgba(15, 23, 42, 0.05)`.
- **Floating Modals & Overlays (L3)**: Valuation drilldowns and tooltip inspections use `backdrop-filter: blur(28px)`, background `rgba(255, 255, 255, 0.95)`, and dynamic shadow `0 20px 40px -8px rgba(15, 23, 42, 0.15)`.

### Border & Light Refraction
Every card features an ultra-fine border gradient or semi-transparent top stroke (`rgba(255, 255, 255, 0.95)`) tapering to subtle bottom border tinting (`rgba(226, 232, 240, 0.6)`), evoking natural glass edge refraction.

## Shapes

The design system uses **Rounded (Level 2)** geometry:
- Default components (buttons, input selects, metric badge tags) utilize `0.5rem` (8px).
- Intermediate cards, KPI containers, and filter panels use `1rem` (16px) radius (`rounded-lg`).
- The primary glass frame enclosure and application shell boundary feature generous `1.5rem` (24px) corners (`rounded-xl`), creating the floating tablet aesthetic seen in the reference visual.
- Floating metric badges, status indicators, and pill-toggles use `9999px` full-pill radiuses.

## Components

### 1. KPI Metric Cards & Confidence Intervals
- **Structure**: Glass card container with top-right sparkline or mini trend indicator.
- **Content**: Subtitle in `body-sm` (`#64748B`), valuation figure in `kpi-metric` (`#0F172A`), and inline dynamic badge.
- **Confidence Interval Strip**: A horizontal gradient bar anchored beneath the valuation number showing P10, P50, and P90 ranges with a clear emerald indicator needle marking the point estimate.

### 2. Status & Market Tier Badges
- **Visuals**: Pill shape (`rounded-full`), padding `0.25rem 0.625rem`.
- **Background**: Translucent tint (12% opacity of the semantic color) with matching 1px semi-solid border.
- **Variants**:
  - `Luxury`: Violet background `rgba(124, 58, 237, 0.12)`, text `#7C3AED`.
  - `Mid-Market`: Cerulean background `rgba(2, 132, 199, 0.12)`, text `#0284C7`.
  - `Entry-Level`: Teal background `rgba(13, 148, 136, 0.12)`, text `#0D9488`.

### 3. Spatial Filter Controller (King County Parameters)
- **ZipCode Dropdown**: Searchable select input with frosted white background, subtle search icon, and auto-complete counts per postal district.
- **Sliders (SqFt, Grade 1-13, Bed/Bath)**:
  - Track: 6px height, background `rgba(226, 232, 240, 0.8)`.
  - Filled Range: Gradient from `#0284C7` to `#059669`.
  - Thumb: 20px white circle with high-elevation drop shadow and `2px` solid `#059669` ring.
  - Grade Indicator: Stepped notches corresponding to King County building grade standards (1-4 Cabins, 7 Average, 11-13 Custom Luxury).

### 4. SHAP Waterfall Attribution Bars
- **Positive Drivers (Increase Value)**: Horizontal emerald bar (`#059669`) anchored to the right, showing feature name (e.g., `+SqFt Living: +$42,500`).
- **Negative Drivers (Decrease Value)**: Horizontal crimson bar (`#E11D48`) anchored leftward (e.g., `-Distance to Tech Hub: -$18,200`).
- **Base Value Baseline**: Dotted neutral guideline indicating King County mean prediction anchor.

### 5. GIS Map Controls & Spatial Legends
- **Map Viewport Controls**: Glass-stacked square buttons (Zoom +, Zoom -, Layer Switcher, Reset Pitch) docked to the top right with 8px radius and frosted white surface.
- **Choropleth Legend**: Floating horizontal pill at bottom center of map viewport illustrating price-per-square-foot density spectrum (`#E0F2FE` to `#0369A1`).

### 6. Interactive ROI Renovation Simulator
- **Toggle Cards**: Checkable cards for upgrades (e.g., "Add 1 Full Bath", "Modern Kitchen Remodel", "Deck Addition").
- **Metrics Feedback**: Immediate estimated cost vs. model-derived value increment, displaying net ROI percentage pill colored green when ROI > 115%.
